# Учебный frontend-проект: ShopProject

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».  
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта
- `index.html` — главная страница магазина;
- `css/style.css` — файл стилей (Flexbox, CSS Grid, БЭМ, переменные);
- `js/main.js` — клиентский скрипт для модального окна и валидации формы;
- `images/` — каталог для графических ресурсов;
- `.gitignore` — файл исключений Git;
- `README.md` — документация проекта.

## Используемые технологии
- HTML5;
- CSS3;
- JavaScript;
- Git & GitHub;

## История выполнения
1. **Практическая работа 1:** создан репозиторий, настроен `.gitignore`, опубликован каркас на GitHub Pages.
2. **Практическая работа 2:** разработана семантическая HTML-разметка стартовой страницы и подключены базовые CSS-стили.
3. **Практическая работа 3:** интегрирована форма заявки, всплывающий диалог (`<dialog>`), валидация полей и вывод статуса отправки.
