# Учебный frontend-проект: ShopProject

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».  
ShopProject — многостраничный сайт учебного интернет-магазина: главная страница, каталог с фильтрами, карточка товара, страница оформления заявки и контакты.

## Контрольная работа №1
Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина с единой навигацией, карточками товаров, таблицей характеристик, формой заявки и модальным окном.

## Использование Flexbox и Grid

- Flexbox — основное меню, меню в подвале, внутренняя структура карточек товаров, кнопки карточек и формы;
- CSS Grid — сетка карточек товаров;
- CSS Grid — страница каталога (фильтры + список товаров);
- CSS Grid — страница товара (изображение + информация) и блок отзывов.

## Позиционирование

- `position: relative` — карточка товара и блок изображения товара как контейнеры;
- `position: absolute` — бейджи «Хит», «Скидка», «Новинка» в карточках и бейдж на изображении товара;
- `position: fixed` + `z-index` — шапка сайта закреплена вверху экрана на всех страницах; чтобы она не перекрывала контент, у `body` задан `padding-top`, а у якорей — `scroll-padding-top`;
- `position: sticky` — блок фильтров в каталоге «прилипает» под фиксированной шапкой при прокрутке;
- `position: fixed` + `z-index` — кнопка «Наверх»;
- модальное окно `<dialog>` отображается поверх страницы.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (модификаторы `--featured`, `--discount`);
- `product` — подробная карточка товара;
- `product-table` — таблица характеристик;
- `reviews`, `review` — отзывы покупателей;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters`, `filters-form` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (модификатор `--page` для отдельной страницы);
- `about` — раздел «О нас»;
- `faq` — частые вопросы;
- `button` — кнопка (модификаторы `--primary`, `--secondary`, `--disabled`);
- `site-footer` — подвал сайта.
