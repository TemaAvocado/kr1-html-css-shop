# Учебный frontend-проект: ShopProject

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».  
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.


## Используемые технологии
- HTML5;
- CSS3;
- JavaScript;
- Git & GitHub;

## История выполнения
1. **Практическая работа 1:** создан репозиторий, настроен `.gitignore`, опубликован каркас на GitHub Pages.
2. **Практическая работа 2:** разработана семантическая HTML-разметка стартовой страницы и подключены базовые CSS-стили.
3. **Практическая работа 3:** интегрирована форма заявки, всплывающий диалог (`<dialog>`), валидация полей и вывод статуса отправки.
4. **Практическая работа 4:** выстроена CSS-архитектура, объявлены системные переменные `:root`, настроены псевдоклассы `:hover`, `:focus-visible`, `:disabled`.

**Контрольная работа 1:** применены Flexbox и CSS Grid, внедрена БЭМ-номенклатура классов карточек, реализовано позиционирование (`relative`, `absolute`, `fixed`).

5. **Практическая работа 5:** создана многостраничная структура сайта, добавлены единая навигация и якорные ссылки.
6. **Практическая работа 6:** добавлены Flexbox-навигация и Grid-раскладка карточек и каталога.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.
